# Як користуватися адмін-панеллю «Семицвіт»

Адреса: **https://zavars296-cyber.github.io/semitsvetik/admin/**

**Вхід.** Email і пароль. Забули пароль — «Забули пароль?», лист прийде на пошту.

**Новий працівник.** На сторінці входу — «Я новий працівник». Після реєстрації власник відкриває «Користувачі та права» → «Надати доступ», обирає роль і розділи.

**Програми, педагоги, новини, розклад.** «+ Додати» → заповнити → «Зберегти чернетку» → «Перегляд» (так сайт виглядатиме) → «Опублікувати». Кнопка «Сховати» прибирає запис із сайту, не видаляючи.

**Фото.** «Фотогалерея» → обрати альбом → «Завантажити фото». Якщо на фото видно дітей — увімкніть «На фото видно дітей» і, якщо батьки погодилися, «Є згода батьків». Без згоди фото не з’явиться на сайті.

**Заявки батьків.** Нові заявки — у розділі «Заявки батьків» і на головній панелі. Кнопка з номером одразу телефонує. Після розмови — «Оброблено». Можна вивантажити в Excel (CSV).

**Пропозиції працівників.** Працівник натискає «Запропонувати» в будь-якому розділі або «+ Нова пропозиція». Власник у «Пропозиції працівників» → «Розглянути» → може виправити текст → «Опублікувати на сайті» або «Відхилити» з коментарем.

**Контакти, графік, тексти.** Розділи «Контакти й соцмережі», «Графік роботи», «Тексти й налаштування». Після «Зберегти зміни» сайт оновлюється одразу.

**Оголошення вгорі сайту.** «Тексти й налаштування» → «Смуга оголошення».
